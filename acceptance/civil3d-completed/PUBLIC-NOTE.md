# Public note

The documents in this folder describe the native Civil 3D round trip as it was recorded. The screenshots, saved drawings, operator records, conversion records and logs they mention are kept privately, because they contain local file paths. Each one is listed with its SHA-256 in `docs/PUBLIC-EVIDENCE-MAP.json`. The files the checks use are here: the source, the converted file, the Civil 3D export, the expected output and the checker.
