Point File Unit Converter

Converts the coordinates in a survey point file between metres, international feet and U.S. survey feet, with exact arithmetic. Every other character stays as it was, and the result is checked before you can save it.

In the converter

  1. Load your point file

    Drop it on the page or click to choose it. It is read on your computer and never uploaded.

  2. Confirm the format

    Check the column preview. PENZD (point, easting, northing…) and PNEZD (point, northing, easting…) look alike, and the wrong choice swaps easting and northing.

  3. Declare the units

    Choose the units your file is actually in, and the units you want. The two feet differ: the international foot is exactly 0.3048 m, while the U.S. survey foot (legacy) is 1200/3937 m. The file itself cannot tell you which one it uses. If you know the true coordinates of one point, enter it under Control points; it can catch a wrong choice.

  4. Tick the confirmation, then Convert & verify

    If the button stays grey, read the line beside it. Changing any setting clears the tick, so tick it again after each change.

  5. Click Point data for import to save

    Nothing is saved until you click it. This is the file for Civil 3D. The report and manifest are records; don't import them. Save complete handoff keeps everything in one page that re-checks itself when you open it.

Into Civil 3D

Use Import Points and pick the point file format that matches the columns you confirmed, for example PENZD (comma delimited).

Make sure the drawing's units match the units you converted to, and that no coordinate transformation is applied unless you intend one.

Check a file later

Open the saved handoff page: it re-checks itself. Or open the converter, convert the same source with the same settings, and use Re-upload saved output to verify.

A pass means the arithmetic is exact to the written decimals and nothing else changed. It doesn't confirm that the right units, columns or survey reference were chosen.

Command line (optional)

The same converter as a Python 3 script, with nothing else to install. It writes the point file plus a report and a manifest beside it; exit code 0 means converted and verified.

Windows (PowerShell)

py -3 pointfile_units.py convert --in points.txt --out points-m.txt --format PENZD --delimiter comma --header no --conversion USFeetToMeters --source-unit-reference "Survey report, sheet 2"

Mac (Terminal)

python3 pointfile_units.py convert --in points.txt --out points-m.txt --format PENZD --delimiter comma --header no --conversion USFeetToMeters --source-unit-reference "Survey report, sheet 2"
