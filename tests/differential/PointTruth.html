Use and share
  1. Save this HTML file and open it in a current Chrome, Edge, or Firefox browser. No installation, account, or connection is required.
  2. Choose a source file. Confirm the format, delimiter, units, and header policy. “P” means point identifier; E / N / Z mean easting / northing / elevation. Column positions never move.
  3. Choose Preview & verify, inspect the output, then save a complete handoff. This single HTML file carries both files, the report, and the app. Opening it rechecks the embedded bytes before showing a pass.
  4. Use Download point file to obtain the converted text for your survey software. Use Check saved point file to verify a downloaded copy.


What is mechanically checked
Decimal inputs are parsed as exact rational numbers. Unit ratios are exact: 1 international foot = 381/1250 metre; 1 US survey foot = 1200/3937 metre. Conversion rounds the product to the requested decimal places. The verifier re-parses source and output, independently rounds the exact product, checks reverse error against half the source token’s decimal quantum, and reconstructs the source at that quantum. It compares all content outside coordinate-value spans, including quotes, whitespace, descriptions, each line ending, and one leading UTF-8 BOM.
The converter and verifier use different rounding procedures, but share the parser and rational primitives. Their separation helps catch mistakes; it is not external certification. The build was checked against a Python Decimal oracle and adversarial fixtures. See the included build notes.


What you still establish
Source units, coordinate-system meaning, axis labels, the authority of a reference, and control-point values come from you. A header is skipped only under your explicit setting. Comments starting with # and blank lines are preserved. Metadata mentioning old units is preserved as text too; inspect that metadata before importing the output elsewhere.
This app performs uniform scaling about zero. It does not transform datums, reproject coordinates, apply an origin offset, correct a survey, or give horizontal and vertical columns different factors. For mixed units, use custom columns that share one factor and record the partial scope clearly. Avoid running already converted coordinates through the same factor again.


Supported input and limits
UTF-8 / ASCII8 MiB source24 MiB output100,000 lines64 columns0–12 output decimals
Comma CSV supports quoted fields and escaped quotes on one physical line. Whitespace files use ASCII spaces, tabs, vertical tabs and form feeds; a trailing multiword description is preserved. Decimal commas, thousands separators, multiline quoted CSV, UTF-16, and multiple BOMs are unsupported. Numeric inputs allow 40 mantissa digits and exponents from −30 to +30. Precision that cannot pass within 0–12 decimals is refused. Identifiers, when mapped, must be nonempty and unique. Custom mappings preserve every unselected column.
Automatic precision tries a suitable starting precision, then every supported precision if necessary; it does not claim to choose the fewest digits. Sequence warnings flag obvious consecutive integers, and cannot detect every incorrect mapping.


Compatibility and resource budgets
This build reads its own pointtruth/1 records and the nominated 1.0.0 baseline build. Other builds are explicitly unsupported. Historical reports stay unchanged and receive a separate new verification record. JSON rejects duplicate keys, fractional or unsafe number literals, ill-formed Unicode, and excessive nesting. Record budget: 4 MiB; encoded handoff: 48 MiB; complete HTML: 49 MiB. Save and reopen apply the same limits.


Integrity and privacy
No data is sent to a service. The app has no external scripts, fonts, or analytics and disables network connections through its content policy. A complete handoff contains the original source, so share it only with recipients who should receive that data. The embedded build and content fingerprints bind the recorded bytes and settings; they do not authenticate a person, a timestamp, or the source’s correctness. Run only copies obtained from a source you trust: an HTML handoff contains executable code.
